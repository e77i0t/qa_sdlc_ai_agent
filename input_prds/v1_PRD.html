Product Requirements Document (PRD)

Stock Market Dashboard (Version 1)

1. Overview

The Stock Market Dashboard is a web-based application developed using Streamlit that provides users with real-time stock data. It fetches stock prices using the Yahoo Finance API (yfinance) and allows users to track and visualize stock performance.

2. Objectives

  • Enable users to monitor real-time stock prices for popular companies.
  • Provide a user-friendly interface for selecting and viewing stock data.
  • Allow users to download and store stock data for future reference.

3. Key Features

3.1 Stock Data Retrieval

  • Users can select from a predefined list of stock tickers (e.g., Apple, Microsoft, Google, Amazon, Tesla, Nvidia).
  • Users can add custom stock tickers to monitor additional stocks.
  • The application fetches real-time stock prices and historical data using the Yahoo Finance API.

3.2 Data Visualization

  • Display of stock performance charts with historical data.
  • Interactive charts showing stock trends over different time periods.
  • Ability to compare multiple stocks on the same graph.

3.3 Data Persistence

  • Saves stock data to a local JSON file for later use.
  • Ensures data is retrievable upon subsequent app launches.
  • Provides an option to export data in CSV format.

4. User Personas

4.1 Retail Investor

Goal: Track stock market performance for investment decisions.
Pain Points: Needs easy access to stock data without complex trading platforms.

4.2 Financial Analyst

Goal: Analyze stock trends and historical performance.
Pain Points: Requires clean, structured data for financial reports.

4.3 Casual User

Goal: Stay informed on market movements for popular stocks.
Pain Points: Prefers an easy-to-use dashboard over technical tools.

5. Functional Requirements

Requirement IDDescription
V1-REQ-001The system must allow users to select stocks from a predefined list.
V1-REQ-002Users should be able to add custom stock tickers.
V1-REQ-003The application must fetch real-time stock prices using the Yahoo Finance API.
V1-REQ-004Stock performance must be visualized using interactive charts.
V1-REQ-005Users must be able to download stock data as a CSV file.
V1-REQ-006The application must save stock data to a local JSON file for future use.

6. Non-Functional Requirements

  • The dashboard should be lightweight and load stock data within 3 seconds.
  • The UI should be responsive and function on desktop and mobile browsers.
  • The system should handle API rate limits gracefully without breaking functionality.

8. Open Questions
